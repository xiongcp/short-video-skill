## 1. 使用说明

- **适配平台**：即梦（Jimeng AI）、可灵（Kling AI）、海螺视频（MiniMax）、Veo 2、Sora 等支持提示词生成的单镜头视频大模型。
- **角色参考图**：请在平台支持角色参考图/垫图时，上传项目目录下的 `ref/host.png`，以锁定主持人“晴”的面部特征、发型发色、呆毛挑染及服饰细节。
- **逐镜生成机制**：每条提示词均具备自包含的规格、画风、角色锁定及负向禁止项，彼此独立，可直接单条复制提交。
- **后期剪辑流程**：
  1. 视频模型生成完毕后，按照 `sh01` 至 `sh10` 的顺序导入剪辑工程（剪映、Premiere 等）。
  2. 将各镜片段裁剪至“估时长度”（丢弃模型首尾多余晃动帧）。
  3. 导入配音音轨（使用 [讲稿.md](file:///private/var/folders/bp/fmq4wtfn57lcl4dd6k7tyj_80000gn/T/svs-scenario-03-SUd0Z8/http-cache/讲稿.md) 进行配音录制或 TTS 生成）。
  4. 按照分镜表要求，在对应时间点添加图解关键字贴字与全片字幕。

## 4. 剪辑与配音指导

1. **片段对齐与裁剪**：
   - 按照 `sh01` 至 `sh10` 的先后顺序将生成的无声视频片段依次排列在主视频轨。
   - 按照分镜表中的估时长度裁剪各片段，优先保留动作清晰、表情生动的中段部分，切除前后多余停顿。
2. **配音轨道叠加**：
   - 使用 [讲稿.md](file:///private/var/folders/bp/fmq4wtfn57lcl4dd6k7tyj_80000gn/T/svs-scenario-03-SUd0Z8/http-cache/讲稿.md) 进行配音录制（语速约 4 字/秒，每句末尾留 0.25 秒微顿）。
   - 可选用剪辑软件自带的清脆自然女声 TTS，或通过 ElevenLabs / Azure TTS 生成配音后导入。
