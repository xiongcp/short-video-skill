# 为什么 HTTP 缓存能让网页变快？

- 受众：不懂网络的普通人
- 目标时长：90 秒（估算约 87 秒，337 字）
- 看完能说清：浏览器把看过的资源在本地存一份副本，下次直接调出来用，省去漫长的网络传输。
- 采用的默认值：比例 16:9，浅色主题
- 来源：无（未提供外部资料）
- 待核实：本期面向零基础受众，已将强缓存、协商缓存等技术术语通俗化为“本地小仓库”与“发暗号核实”，需确认此简化程度是否符合预期
- 确认状态：待确认（revision 2）

## s01 两次打开的差距（约 20 秒）

你有没有发现，第一次打开某个网页往往要等一下？
但再次打开时，常常唰地一下就瞬间加载好了。
难道是家里的宽带突然加速了吗？
其实是浏览器使出了一个偷懒绝招，叫 HTTP 缓存。

## s02 第一次打开网页（约 17 秒）

这就像网购，第一次买东西，包裹要从远方的总仓库发货。
跨越千里送过来，路上自然需要花时间等待。
但在签收的同时，楼下的快递驿站顺手把货物存了一份。

## s03 第二次直接调取（约 16 秒）

当你第二次打开同一个网页，情况就不一样了。
浏览器翻看本地的小仓库，发现需要的文件还在。
它直接从本地设备调取内容，省去了漫长的网络传输。

## s04 内容变了怎么办（约 18 秒）

那要是网上的内容更新了，本地存的副本不就过时了吗？
别担心，浏览器会先向服务器发一条极短的消息核对。
内容没变就继续用本地副本，变了才重新下载最新版本。

## s05 缓存的核心秘密（约 16 秒）

所以，HTTP 缓存的提速秘诀其实非常朴素。
就是就近留一份看过的资源，能少跑路就少跑路。
这样不仅让页面瞬间加载，还能悄悄省下你的手机流量。
