# AI Animation Studio 升级项目计划书

设计基线 v1.1 · 2026-11-19 · 交接给后续实施模型和项目所有者。

## 项目目标与本轮交付

用一位原创日系动漫主持人制作有来源、可逐镜编辑的中文知识节目。个人创作者输入主题、资料或已有稿件，先审核研究和脚本，再试听样片、审核成片并确认导出。正式规格为 1–3 分钟短片和约 8 分钟章节节目。两档的角色资产和时间基一致。

本轮交付包括[升级详细设计](升级详细设计.md)、[TDD 执行计划](TDD执行计划.md)、[验收计划](验收计划.md)、[模型提示词](模型交接提示词.md)。已完成的离线工作及实测证据见[交接状态](交接状态与证据.md)。下一位模型从 T01 开始实现生产运行时。

## 研发范围和决策权

| 项 | 纳入本期 | 负责人及决定依据 |
| --- | --- | --- |
| 内容生产 | 主题拆解、带来源的论点、分段口播、术语读音、两档时长、编辑与返修 | 内容负责人审核 G1/G2，事实冲突带来源定位退回 |
| 原创美术 | 一位固定服装主持人、有限视角、高质量表情手势、三类场景与图解 | 美术交原画、PSD、Rig、能力表和使用范围。所有者审样片 |
| 制作系统 | 本地 Studio、项目 API、受控适配器、对齐、逐镜烘焙与合成、持久化作业、缓存、预算 | 实施模型提交代码、红绿记录和实际资产。QA 独立复验 |
| 交付 | MP4、SRT、WAV、可编辑工程、来源、章信息、审核、费用与 QA | 人类验 G3/G4/G5，核对与批准哈希相同的包 |
| 可选渠道 | 有明确叙事价值的生成式插镜。默认关闭，可用获准的静态或程序图解替代 | 所有者选择是否启用，提供合法参考、报价与上限。按 A16 单列结论 |

后端沿用 Node.js / TypeScript、SQLite 和受控本地目录，角色顺序烘焙后进入 Remotion 与 FFmpeg。多角色物理互动、批量 SaaS、多人实时协作、训练基础模型留在当前范围之外。旧 PDF 作为技术脉络进入设计，部署、采购或提交外部任务以当前项目授权为准。

## 阶段、依赖与放行

下表是原工作室方案的 24 周基线与 2 周缓冲，周数为规划假设。可先按任务依赖推进，每个阶段以实物和有效审批放行。工程放行与单期节目的 G1–G5 使用不同记录。

| 阶段 | 参考窗口 | 本阶段必须产物 | 放行证据或处理 |
| --- | --- | --- | --- |
| M1 技术与美术验证 | W1–4 | W2 一段 10–15 秒有声技术片，W4 一段 45–60 秒的原创角色样片及能力边界 | 可重新运行技术链，三种底色和嘴型可审。原创资产未到时技术片可先行，美术门保留待验 |
| M2 可编辑工程 | W5–8 | 一个 60 秒可编辑工程、三类场景、稳定 ID、项目和审核事件、镜头与角色面板 | 重开工程定位原镜头，拒绝非法动作与过期编辑，检查保留的旧版本 |
| M3 主题到短片 | W9–12 | 来源、G1/G2、配音/导入、对齐、编译、可播放短片 | 60/120/180 秒各有证据，至少一支实际节目完成全部审核，低置信读音能手校 |
| M4 可靠性 | W13–16 | 镜头/章缓存、变更影响、预算对账、中断恢复及局部重渲 | 同一付费意图只有一笔实支，字幕返修不触发 TTS，坏缓存可定位 |
| M5 画质和 QA | W17–20 | 固定镜头组、几何与帧级报告、联系表、口型校准、最终媒体交付回读 | 保留全部检测样本与人审意见，修复后重放负例。生成插镜按项目选择单验 |
| M6 连续生产 | W21–24 | 连续三期真实约 8 分钟节目，每期均有完整可编辑包、成本和签收 | 三期共同满足 A15。至少一部验证跨章返修与恢复，逐期留存全片回看记录 |
| 缓冲 | W25–26 | 关键缺陷返修与回归 | 补充实物与审核后再升级项目状态 |

首轮实现先走 T01 的薄切片。工程计划中的 T02/T03 解决状态和可计费调用，T04/T05 处理事实及声音，T06 提供正式美术，T07–T09 打通时间线、烘焙和渲染。T10/T11 完成 QA、交互及交付。T12 负责真实节目的取证，T13 是可选渠道。部分美术及样片工作可与研发交错，任务的完成依赖以[执行计划](TDD执行计划.md)为准。

## 人力、成本与风险

沿用原计划的估算口径，两名工程师负责工作台/服务与渲染/QA，美术/绑定约 0.4 FTE 前置，内容所有者每周预留 2–4 小时审核。单模型或单人接手时按任务完成数和阻塞项重新估期。上线所需的人类美术和签收不能由代码测试折算。

成本账本按项目、任务、镜头和供应商采集。单位成片分钟成本 =（实付生成费＋渲染算力＋存储＋分摊资产和人工返修）÷ 实际成片分钟。分别记录冷/热渲染墙钟时间、峰值内存、重复生成次数、缓存命中和人审时长。预算未配置时允许读资料、写脚本和离线校准，付费提交等待项目限额。

| 触发信号 | 当期动作 | 恢复所需证据 |
| --- | --- | --- |
| 原创 Rig 迟到、嘴型或手指极值穿帮 | 工程用许可清楚的测试夹具跑技术链，退回对应美术参数 | 新资产版本、对照图、W4 原创样片 |
| 实际配音越出片长或术语读错 | 局部重写/重配，重排锚点和受影响的审核 | G2 新版本、实测 WAV、帧数与段落差 |
| 供应商提交回执丢失、账单不明 | 保留有效预留，按原业务键查询 | 提交回执、对账结果、唯一结算记录 |
| 长片晚章返修引发全片重做 | 比较局部层键和绝对拼接键，检查依赖投影 | 新旧命中列表、实际调用数、两部输出的时长 |
| 渲染后端、插件、字体或许可未到位 | 记录 doctor 能力与缺口，做其他就绪任务 | 同机探针、实际技术片、授权清单 |

## 完成定义

本轮计划交接以文件、实际离线测试、媒体校准报告和交接包复验为准。生产完成须通过 A01–A15，记录实际使用的可选渠道状态，交付可重开工程、媒体、来源和人类签收。任何 PASS 都必须绑定具体版本、证据等级和产物。
