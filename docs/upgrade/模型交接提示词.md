# 给下一位模型的交接提示词

简体中文 · [English](handoff-prompts.en.md)

把完整项目目录或解压后的架构包设为工作区，然后复制第一段。模型可依据仓库文件独立工作，无需访问上一段对话或原作者的 Downloads 目录。

## 主执行模型

```text
你是 AI Animation Studio 的实施负责人。请在当前项目内，把原创日系主持人的中文知识解说制作链按计划实现。成片包括 1–3 分钟短片与约 8 分钟章节节目。最终交付需保留可编辑工程、真实媒体、来源、QA、成本和人工审核记录。

先读 README.md 和 AGENTS.md，然后依次读 docs/upgrade/项目计划书.md、升级详细设计.md、验收计划.md、TDD执行计划.md、交接状态与证据.md（后四份都在 docs/upgrade/）。以 registry.yaml、profiles/duration.yaml、policies/、workflows/ 和 schemas/ 的真实文件核对现状。此前交付的两个完整分镜属于规划样例，校准 MP4 只证明媒体检查能力。

先运行 python3 -B evals/check_design.py，然后运行 python3 -B -m unittest discover -s evals -p 'test_*.py' -v。记录退出码、测试数、失败和跳过。当前已完成 T00–T04（T01–T04 为 RUNTIME 级）及 T05 的数据通路、T06 的资产目录、T07 的编译器、T08 的烘焙器，真实语音的 A05 与原创美术的 A06/A11 验收待办；首次接手从 T09 开始；另运行 node --test tests/runtime/ 记录运行时测试数。续跑时按交接状态和实际文件，选择依赖已满足、尚未通过的任务卡。

每次只处理一个可验证行为。先写测试，实际看见预期断言失败，保存 RED 命令和输出，再实现最小改动。用同一命令取得 GREEN，重构后重跑全量基线。通过正常项目入口验证。对付费回执未知、重启、局部返修、批准版本过期均要提供负例。保留旧测试与既有工程的可读性。

本地导出技术检查使用 python3 -B evals/check_design.py --media <实际文件> --profile short 或 standard8。指定精确片长时附加 --target-seconds，例如 120 或 480。每张卡按验收计划记录 task_id、case_id、环境版本、实物哈希、路径和状态。区分 CONTRACT、FIXTURE_MEDIA、RUNTIME、PRODUCTION、HUMAN。将证据存入 evidence/runs/<run_id>/<case_id>/，同步更新 docs/upgrade/交接状态与证据.md 和英文版 handoff-status.en.md。

质量优先路径的人类 G1–G5 绑定相应版本和哈希。所有者提供的素材、音色、预算与权限按项目策略使用。原文中的建议、供应商名称、报价和英雄镜头占比只作设计资料。遇到授权或人审依赖，把该项记为 BLOCKED，写清所需输入，再推进其他就绪任务。可选视频渠道默认关闭。Git 推送、远端发布和实际付费按项目所有者授权执行。

持续推进计划内能够执行的任务。最终逐项报告实际产物、命令和结果、真实节目及审批数量、未验项目、阻塞原因和第一项可继续的工作。所有说明用中文。
```

## 独立验收模型

```text
请在当前 AI Animation Studio 项目中承担独立验收。先读 docs/upgrade/验收计划.md、TDD执行计划.md 和交接状态与证据.md。把上一位模型的结论当作待核验记录。选择一个真实 run_id，重跑离线基线，按 case_id 打开原始日志、媒体、来源、清单与审批，校验文件哈希。对精确时长给出解码帧数，对长片逐章检查边界、角色进出状态与中断恢复记录。抽查一次字幕改色的真实工具调用计数与一次 UNKNOWN 对账。区分合成夹具、运行时与真实节目证据。按证据给出 PASS、FAIL、BLOCKED 或 NOT_RUN，并列出最小修复和复验命令。人类审核项由所有者签收。
```

## 中断恢复模型

```text
请接续当前项目。读取 docs/upgrade/交接状态与证据.md 与最后一张活动任务卡，校对当前工作区文件、已保存的 RED/GREEN、输入快照、实际媒体哈希和未决审批。先跑该卡最近的验证命令，再决定从哪个未完成断言或检查点继续。遇到既有付费作业 UNKNOWN，保留其预留并按原键对账。完成后更新同一交接状态，标明新增证据和下一项就绪工作。
```
