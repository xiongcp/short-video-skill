## 4　从解压目录复跑

进入含 `registry.yaml` 的目录，使用装有 `evals/requirements.txt` 中依赖的 Python。全量媒体测试需要可执行的 FFmpeg 和 ffprobe，以及 H.264 / AAC 编码器。请记录测试总数和 skipped 数，缺少媒体工具时把对应验证记为 BLOCKED。

```sh
python3 -B evals/check_design.py
python3 -B -m unittest discover -s evals -p 'test_*.py' -v
python3 -B docs/upgrade/evidence/replay_media.py
```

真实成片就绪后，在有实际 MP4 的路径上运行 `python3 -B evals/check_design.py --media renders/final.mp4 --profile standard8 --target-seconds 480`。可选的精确秒数由本期约定决定。缺少真实语音、原创画面或授权人签收时，节目验收继续使用对应的未执行或阻塞状态。
