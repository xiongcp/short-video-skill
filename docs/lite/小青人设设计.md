# 小青人设设计（H）

- 日期：2026-11-25
- 状态：设计已在对话中确认（owner 2026-11-25：性格"好奇的伙伴"、招牌特征"A 呆毛"、触发方式"混合"、外观与动作两部分"可以"）；书面文档待 owner 确认
- 关系：展开 [个性化路线图](个性化路线图.md) §6.2；修订 [火柴人主持人设计](火柴人主持人设计.md) 的形象、表情和动作库，冲突处以本文为准

## 1. 目标

- 小青有自己的性格：好奇的伙伴，和观众一起发现答案。爱凑近看、托腮琢磨，想通了打响指，偶尔被结论吓一跳。
- 540p 剪影里，不看围巾颜色也能认出小青。
- 表情和动作更夸张，让人一眼看出情绪。
- 旧项目不改也会变生动；agent 也能在分镜里点名用新动作。
- 不加文件、不加依赖，不改 `rights.json` 的 `usage`。

## 2. 已确认的决定

| # | 问题 | 结论 |
| --- | --- | --- |
| H1 | 性格 | 好奇的伙伴 |
| H2 | 招牌特征 | 头顶一根呆毛，跟着情绪变形（设定图草稿 A，见 §3.1） |
| H3 | 主题服装 | H 只做画法，先做 4 件；哪个主题穿哪件由 S 阶段的视觉世界决定 |
| H4 | 性格动作由谁触发 | 混合：agent 可以在分镜里点名；句子没写动作时，渲染器按句意自动挑；呆毛变形、待机小动作、惊讶联动都自动加 |
| H5 | 口头禅 | 不加。V 阶段已定默认不加固定的开场自我介绍（声音人设设计 D4） |

## 3. 外观

### 3.1 呆毛

- 从头顶正中长出，跟着头转；墨线粗细与身体线条相同（`ink.width`），剪影里清楚可见。
- 5 种形状，用头部单位（半径 R = 1）的控制点写在 `manifest.json` 的 `ahoge.shapes` 里：

| 形状 | 样子 | 用在哪些表情 |
| --- | --- | --- |
| `curl` | 向前弯的小卷 | `explaining`、`focused` |
| `question` | 卷成问号 | `curious` |
| `straight` | 竖直，略带抖动 | `surprised` |
| `droop` | 向前耷拉 | `worried`、`frustrated` |
| `spring` | 弹簧卷 | `happy`、`proud`、`amazed` |

- 换表情时，形状在 0.2 秒内按控制点渐变。
- 走路、跳起、吓一跳、猛回头时，呆毛用和围巾一样的弹簧（固定步长 1/240 秒）晃动，再回到当前形状。
- 戴帽子类服装时，呆毛从帽顶钻出来。

### 3.2 表情更夸张

- 眼睛、眉毛、嘴的变化幅度加大约 25%：放大 `figure.face_scale` 之外各表情自己的 `eye_scale`、眉毛角度和抬高量，不改五官位置。
- 情绪符号（问号、感叹线、汗滴、颤抖线、星星）放大约 1.3 倍。
- 头部挤压和拉伸：`surprised`、`happy`、`amazed` 拉长 6%，`worried`、`frustrated` 压扁 6%。表情切换后 0.3 秒内弹回原样，之后保持正圆。
- 新表情 `amazed`：星星眼（眼睛画成四角星），嘴是张开的笑，符号用 `sparkle`。用在"想通了""原来如此"的时刻，常和 `snap` 一起用。

### 3.3 服装机制

- `project.json` 新增可选字段 `settings.outfit`，全片一套。缺省或 `none` 是不穿。
- 先做 4 件，画法写在 `rig.mjs`，尺寸写在 `manifest.json` 的 `outfits` 里：

| `outfit` | 样子 |
| --- | --- |
| `glasses` | 大圆框眼镜（设定图草稿 C 的画法） |
| `hardhat` | 安全帽 |
| `chef_hat` | 厨师帽 |
| `apron` | 围裙，从胸口到大腿 |

- 服装不遮住呆毛和围巾；`glasses` 跟着脸转，`apron` 跟着躯干转。

### 3.4 参考图与描述

- 用 `npm run export-host` 重新导出 `host-ref.png`、官网速查表和首页插图。速查表加上呆毛的 5 种形状、`amazed`、5 个新动作和 4 件服装。
- `profile.json`：
  - `style_lock` 加一条"头顶一根会随情绪变形的呆毛"；
  - `prompt_lock` 的中英文各加一句呆毛的描述。L0 提示词包靠它让外部模型画对小青。
- `rights.json` 不动。

## 4. 动作

### 4.1 新动作

追加在 `gesture` 枚举末尾，旧名字和旧动作不变：

| `gesture` | 类型 | 样子 | 什么时候用 |
| --- | --- | --- | --- |
| `snap` | 一次性，0.7 秒 | 举手打一下响指，手边冒一下星星 | 想通了、揭晓答案 |
| `lean_in` | 保持 | 上身前倾，手搭在眉骨上，看着焦点元素 | 凑近看细节、提出问题 |
| `startle` | 一次性，0.8 秒 | 往后一缩，双手抬起，呆毛竖直 | 意外的结论 |
| `double_take` | 一次性，1 秒 | 头先转开，再猛地转回来看焦点 | "等一下，再看一眼" |
| `scratch_head` | 一次性，1.2 秒 | 一只手挠头顶 | 困惑、"这就怪了" |

- 一次性动作做完，回到之前的保持型动作，和现在的 `wave`、`tap` 一样。
- 角度写在 `manifest.json` 的 `poses` 里，不超出关节范围；`lean_in` 和 `double_take` 的视线落在焦点元素上（沿用 `aimArmAt` 和 `gaze`）。

### 4.2 自动挑选

句子没写 `gesture` 时，渲染器按句意自动挑一个动作（`motion.mjs` 的 `inferSentenceBeat`）。现在的规则保留，再加三条：

| 句意 | 判断方法 | 候选动作（按顺序，跳过和上一句相同的） |
| --- | --- | --- |
| 问句 | 现有的问句规则 | `lean_in`、`think`、`shrug` |
| 揭晓 | 含"原来""答案是""所以说""这就是" | `snap`、`present`、`emphasize` |
| 意外 | 含"居然""竟然""没想到" | `startle`、`double_take`、`emphasize` |

- 规则从上往下匹配，"揭晓"和"意外"排在现有的感叹句规则前面。
- 自动挑出的 `snap` 每期最多 2 次，超出后改用候选里的下一个，保持招牌感。agent 点名的 `snap` 不受限制。

### 4.3 待机小动作

- 同一个保持型动作持续 3 秒以上、期间没有新的动作或走位指令时，每隔 3–4 秒插一个小动作。
- 小动作只叠加在当前姿势上，不打断手上的动作：
  - 东张西望：视线和头部转向一侧再回来；
  - 踮脚：身体抬高一点再落下；
  - 呆毛弹一下。
- 插哪个、什么时候插，由镜头的 seed 决定，同一镜头每次渲染都一样。走路时不插，一次性动作进行中也不插。

### 4.4 惊讶联动

表情切到 `surprised` 或 `amazed` 时，呆毛弹直再回弹，身体轻轻往后缩约 0.3 秒，原来的动作不变。

### 5.1 预算

owner 2026-11-25 决定：一次 L0 要读的 skill 文件上限从 30 KB 调到 100 KB，前提是不碰各家 agent 的限制。2026-11-25 查到的限制如下：

| Agent | SKILL.md 和其他文件 | 描述（description） | 来源 |
| --- | --- | --- | --- |
| Hermes Agent v0.23.4 | agent 自己写入时，SKILL.md 和每个文本文件不超过 100,000 字符，其他文件不超过 1 MiB；手工放入或从 hub 安装的 skill 没有硬限制 | 最多 1024 字符；技能索引默认只显示前 60 字符（`skills.index_desc_limit` 可调到 1024） | 源码 `tools/skill_manager_tool.py`、`agent/skill_utils.py`、`tests/tools/test_skill_size_limits.py` |
| Claude Code | 没有大小上限，建议 SKILL.md 不超过 500 行；上下文压缩后每个已调用的 skill 只保留前 5,000 token（合计 25,000） | 和 `when_to_use` 合计超过 1,536 字符会被截断；技能列表占上下文的 1% | code.claude.com/docs/en/skills |
| Codex | 选中后读完整的 SKILL.md；有用户报告称过长的文件只读前 200–260 行，未经官方确认 | 技能列表占上下文的 2%，未知时 8,000 字符 | developers.openai.com/codex/skills |
| Antigravity（agy） | 文档没有写限制 | 文档没有写限制 | antigravity.google/docs/skills |
| Agent Skills 规范 | 建议 SKILL.md 不超过 500 行、5,000 token | 1–1024 字符 | agentskills.io/specification |

据此：

- 一次 L0 要读的 skill 文件合计上限改为 100 KB。
- 单个文件的上限不变：`SKILL.md` 不超过 150 行、8 KB（远低于 Claude Code 压缩后保留的 5,000 token，也避开未经确认的"超过约 8 KB 只加载描述"的报告）；每份 reference 不超过 250 行、10 KB（避开 Codex 只读前 200–260 行的报告）。内容变多时拆成新的 reference，不把单个文件写长。
- skill 目录仍不超过 45 个文件、5 MB；本阶段不加文件。
- 描述的前 60 个字符要能说清这个 skill 做什么（Hermes 默认只显示这么多）。现在的描述前 60 个字符是"把主题、资料或已有讲稿做成中文知识解说视频：输出方案、口播讲稿、分镜和交给外部视频模型……"，满足要求。
- 以上各项都由 `tests/budget.test.mjs` 检查。

## 6. 测试（先写测试）

- schema、`manifest.json`、`profile.json` 三处的表情和动作名单一致（已有测试覆盖，名单变了要跟着过）。
- 呆毛：每种表情画出 `data-part="ahoge"`，形状与 §3.1 的表对应；跟着头转（头转 30°，呆毛根部的位置跟着转）；同一输入画出同一段 SVG。
- 渐变：换表情后 0.1 秒的呆毛控制点在新旧形状之间，0.2 秒后等于新形状。
- 弹簧：跳起时呆毛尖端偏离静止位置，1 秒内回到静止位置 2 px 以内。
- 新动作：5 个都能解析，所有关节角度在 `manifest.joints` 的范围内；一次性动作做完回到之前的保持型动作。
- 星星眼和头部挤压：`amazed` 的眼睛是四角星；`surprised` 切换后 0.1 秒头部纵向半径比横向大，0.3 秒后相等。
- 服装：4 件都画得出（`data-outfit`），戴 `hardhat` 和 `chef_hat` 时呆毛仍在帽子上方。`settings.outfit` 写错时 schema 和 `check.mjs` 报错。
- 自动挑选：问句挑到 `lean_in`；"原来……"挑到 `snap`；"居然……"挑到 `startle`；连续两句不挑同一个；一期里第 3 个自动 `snap` 改成下一个候选。
- 待机小动作：保持 3 秒以上才出现；同一镜头渲染两次结果相同；走路和一次性动作期间不出现。
- 旧项目：不写新字段的项目照常通过自检和渲染。
- 导出：`host-ref.png`、速查表、首页插图里记的 SVG 哈希与当前 rig 一致（已有测试覆盖，重新导出后通过）。
- 预算：§5 的各项上限（已有测试覆盖）。
