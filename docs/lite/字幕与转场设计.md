### 1.2 根因

- **数字**：[script.md](../../skills/topic-to-video/references/script.md) 要求“数字按读法写”，配音才读得对；字幕直接用口播文本，所以也是汉字。段落的 `pronunciation` 本来就只改配音、不改字幕，但只用于个别词。
- **断行**：`timing.mjs` 的 `subtitlePages` 只保证阿拉伯数字和英文不拆，中文按字数平分；还会把一个小句的第一行拼到上一页，后半句留到下一页。
- **转场**：`scene.mjs` 的 `evaluateFrame` 让旧画面淡出和新画面淡入同时进行，中段两层文字都半透明；有共享元素时，新标题也从第 0 秒开始淡入。

## 3. 数字双轨

### 3.1 数据

- `sections[].text` 是显示文本，也就是字幕和讲稿.md 里看到的样子。schema 和字段都不变。
- 配音文本不写进 `project.json`，由新文件 `scripts/lib/reading.mjs` 的 `toSpoken(text, pronunciation)` 现算，返回 `{ spoken, spans }`：
  1. 按 `pronunciation` 的顺序替换术语，结果与现在的 `applyPronunciation` 相同；术语互相包含时，先写的先替换，被替换的部分不再参与后面的替换；
  2. 把其余阿拉伯数字按 §3.2 转成读法；
  3. `spans` 记下每处替换在显示文本里的起止位置和读法；没有替换的文字一一对应。

### 3.2 读法规则

| 讲稿写法 | 读法 | 规则 |
| --- | --- | --- |
| 15.07%、3.7%、-2.3% | 百分之十五点零七、百分之三点七、负百分之二点三 | 百分号移到前面读；数字前单独的 `-` 读“负” |
| 1.4、0.5 | 一点四、零点五 | 小数点后逐位读 |
| 3600点、5300只、1005、110、15 | 三千六百点、五千三百只、一千零五、一百一十、十五 | 整数按数值读，最多 12 位；10–19 开头不读“一” |
| 1.4万亿、2万亿元、6000亿 | 一点四万亿、两万亿元、六千亿 | 数字后面的“万”“亿”照读 |
| 2个、2倍、2点、2到3倍、2000、20000 | 两个、两倍、两点、两到三倍、两千、两万 | 单独的 2 在量词或“万、亿、千、百”前、在区间开头读“两”；千位、万位、亿位上打头的 2 读“两” |
| 11月27日、2月、7月 | 十一月二十七日、二月、七月 | “月、日、号”前的 2 读“二” |
| 12点半、14:05、14:00 | 十二点半、十四点零五分、十四点 | `时:分` 读成几点几分，整点不读分 |
| 2026年 | 二零二六年 | 四位数后面紧跟“年”时逐位读 |
| 第3 | 第三 | 序数不读“两” |
| 2-3倍、2~3倍 | 两到三倍 | 两个数之间的 `-`、`~` 读“到” |
| 5,300只 | 五千三百只 | 先去掉千分位逗号 |
| 007、000001 | 零零七、零零零零零一 | 0 开头的多位数逐位读 |
| 5G、H100、GPT-5、4K | 不转换 | 和字母相连的数字交给配音引擎 |
| 304、600519、科创50 | 不按数值读时写 `pronunciation` | 读数器会读成“三百零四”“六十万零五百一十九”“科创五十” |

量词表写在 `reading.mjs` 里，至少包括：个 只 位 名 人 家 户 种 项 条 次 回 遍 倍 天 周 年 岁 元 块 股 手 份 批 件 本 张 台 辆 篇 首 部 页 杯 瓶 斤 吨 米 点。

### 3.3 用到读法的地方

| 位置 | 现在 | 改后 |
| --- | --- | --- |
| 配音（`tts.mjs`，含试听） | 送 `applyPronunciation` 的结果 | 送 `toSpoken().spoken`，缓存键也按它算，`applyPronunciation` 随之删除。讲稿里没有阿拉伯数字的旧项目，配音文本逐字不变，缓存不失效 |
| 词时间（`timing.mjs` 的 `estimateWords`） | 按显示文本分配：汉字 1 份，数字按位数 | 仍输出显示文本的词，`spans` 里的每处按读法字数分配，例如“15.07%”读“百分之十五点零七”，按 8 个字算。cue 的 `at` 照旧写显示文本，例如 `"at": "11.61%"` |
| 配音引擎给出逐词时间时 | 词是配音文本，`at` 对不上就按比例估 | 按 `spans` 把时间换算回显示文本；两边的字对不齐时，退回在引擎给的说话区间里按读法分配 |
| 估时（`project.mjs`） | 数显示文本的字 | 数配音文本的字。每秒 4.5 字本来就是按念出来的字校准的 |
| QA（`qa.md`） | 无 | 新增“读法对照”：逐句列出“写法 → 读法”；人工复核项加“数字读法：`not_checked`” |
| 自检（`check.mjs`） | 无 | 新增警告 `HANZI_NUMBER`，见 §3.4 |

### 3.4 自检 `HANZI_NUMBER`

讲稿的句子里出现下面的写法时报警告，每句一条，列出命中的写法，提示改成阿拉伯数字：

- “百分之”后面跟数字，如百分之十五点零七（“百分之百”除外）；
- 汉字小数，如三点七、一点四（“一点”后面不跟数字时不算）；
- 两字以上、含“十、百、千、万、亿”的数字，如二十七、四百、三千六百、两万亿；
- 汉字日期，如十一月二十七日、三月五日；
- 四位汉字年份，如二零二六年；
- 三个以上连着的数字字，如三零四。

不报：四股力量、第一、一点、一起、一些、十分、千方百计、万众一心、两到三倍、三五个、七八成。

### 3.5 讲稿写法

[script.md](../../skills/topic-to-video/references/script.md) 里“数字按读法写”一条换成：

- 数据、百分比、金额、日期、时间、代码写阿拉伯数字，例如“科创50大涨15.07%”“11月27日”“12点半”；计数、序数和固定说法照旧写汉字，例如“四股力量”“第一”。
- 配音读法由渲染器自动生成。不按数值读的数字和约定读法写进本段 `pronunciation`，例如 `{"term": "304", "reading": "三零四"}`、`{"term": "科创50", "reading": "科创五零"}`。

## 4. 按词断行与翻页

### 4.1 不拆的整体

1. **数字组**：数字开头，连同 `.` `,` `:` `%` 和紧跟的单位字（年 月 日 号 时 分 秒 点 半 万 亿 千 百 倍 元 只 个 家 位 人 次 天 岁 股 手）；中间的“到、至、-、~”后面接着数字时一并算进去。例如 3.7%、3600点、12点半、11月27日、1.4万亿、2到3倍。
2. **关键词**：本镜 cue 的 `at`、本镜画面关键词（与 `VISUAL_NOT_IN_NARRATION` 用的同一份）和本段 `pronunciation` 的 `term`，只取 2–6 字的。
3. **英文词**：字母开头，连同后面的字母、数字和 `.` `+` `-`，例如 GPT-5、H100。
4. **其余文字**：用 `Intl.Segmenter('zh-CN', { granularity: 'word' })` 分词。它是 Node 自带的，不加依赖；缺分词数据的精简版 Node 会逐字切开，仍能靠 1–3 和 §4.2 的扣分断行。

整体之间重叠时合并成一个，例如关键词“科创50”和数字组“50”合成“科创50”。

### 4.2 选断点

- 先在逗号、顿号、分号、冒号处切成小句（现有 `splitClauses`），每个小句另起一行；夹在两个数字之间的英文逗号和冒号（5,300、14:05）不切。行尾的逗号类标点照旧去掉，句末的 `。！？` 跟着最后一个整体。
- 宽度沿用 `frame.mjs` 的 `textBox`：汉字和全角标点算 1，其余字符算 0.6。竖屏每行最宽 12（60 px 字号约 720 px，在 740 px 的字幕宽度以内），每页最多 2 行，都是 `frame.mjs` 的现有值。
- 小句放不进一行时，只在整体之间断开，行数取最少；同样行数的断法取扣分最少的：
  - 各行宽度与平均宽度之差的平方和；
  - 断点任意一侧是分词没认出的单字（不在整体里、也不是虚词）时，每处加 4；
  - 下一行以“的 了 着 过 吗 呢 吧 啊”开头时加 4；
  - 扣分相同时取靠前的断点。
- 虚词表：的 了 和 与 及 或 在 是 把 被 从 向 对 给 跟 也 都 还 就 才 又 再 很 更 最 不 没 有 让 为 以 于 而 并 但 却 则 即 每 各 该 这 那 其 此 之 将 已 曾 正 到。
- 单个整体比一行还宽时，才在它内部逐字切开。
- 权重 4 由 §4.5 的例句定下，测试锁住。

### 4.3 分页

- 一个小句的几行放在同一页。当前页剩下的行放不下这个小句时，整个小句换到新的一页。
- 只有超过 2 行的小句才拆到几页，每页 2 行。

### 4.4 翻页时间

- 新函数 `captionPages` 返回一句话每页的行和相对句首的起止时间：第一页从句子开始出现，之后每页在它第一个整体开始念时出现（用 §3.3 的词时间），到下一页出现为止；最后一页留到句子结束后 120 毫秒（现有值）。
- 画面字幕（`scene.mjs` 的 `subtitleItems`）和 `captions.ass`（`encode.mjs`）都用 `captionPages`。现在 ASS 按整句时长等比例切、画面按说话区间切，两边会差开。
- 横屏字幕仍是单行、按小句切换、不折行，切换时间也改用 `captionPages`（每个小句一页，不限宽）；12 字以内的句子和只有一个小句的句子照旧整句显示。
- `captions.srt` 仍是一句一条，内容是显示文本。

### 4.5 例句

取自这次成片，写进测试。“/”是同页换行，“‖”是翻页。

| 原来 | 改后 |
| --- | --- |
| 科创五零大涨百 / 分之十五点零七 ‖ 创业板涨百分之 / 十一点六一。 | 科创50大涨15.07% / 创业板涨11.61%。 |
| 沪指涨超百分之三点 / 七站稳三千六百点 ‖ 超五千三百只飘红。 | 沪指涨超3.7%站稳3600点 / 超5300只飘红。 |
| 国内算力需求还在 / 订单自然流向国 ‖ 产芯片和设备。 | 国内算力需求还在 ‖ 订单自然流向 / 国产芯片和设备。 |
| 第三股力量 / 是中午十二点半国常 ‖ 会放出稳市大招。 | 第三股力量 ‖ 是中午12点半国常会 / 放出稳市大招。 |

与设计确认时的示意相比：按显示宽度算，第 2 句的第一个小句放得进一行；第 4 句的断点在“国常会”之后，两行宽度更接近。两处都不拆词。

## 5. 转场先退后进

### 5.1 现状

| 种类 | 用在哪 | 时长 | 问题 |
| --- | --- | --- | --- |
| `cut` | `"transition": "cut"` | 0 | 无 |
| `morph`，有共享元素 | 前后两镜有相同元素 | 0.4 秒；`full` 进出带小青的版式 0.6 秒 | 新标题从第 0 秒开始淡入，旧标题 0.2 秒才退完；新元素 0.15 秒就开始淡入 |
| `morph`，无共享元素 | 两镜都带小青，或版式切换 | 同上 | 旧画面淡出与新画面淡入同时进行 |
| `crossfade` | 其余 | 0.3 秒 | 同上 |

另外，`full` 进出舞台时，场景背景在第一帧直接出现或消失（109 秒那次可见旧卡片和书架同框）。

### 5.2 改法

- 转场仍在新镜头开头，时间轴和配音不动。
- **退场段**（前 45%）：旧镜头独有的标题、标签和物件透明度 1 → 0，同时缩到 0.96 倍，曲线 `easeInOutCubic`。
- **进场段**（后 55%）：新镜头独有的标题、标签和物件从 0.96 倍放大回原大小，透明度 0 → 1，曲线 `easeOutCubic`。
- 前后共享的元素整段从旧位置平滑移到新位置，与现在一样。
- `crossfade` 时长 0.3 → 0.4 秒，否则拆成两段后每段太急；`morph` 时长不变。
- **场景背景**：`full` 进舞台时，背景在进场段淡入；舞台进 `full` 时，背景在退场段淡出；前后场景不同的两个舞台镜头，旧背景退场、新背景进场；场景相同不动。
- 只用 `ease.mjs` 现有的曲线，不加新曲线（[出片质量设计](出片质量设计.md) §7.1）。

### 5.3 不变

小青的连贯动作（舞台之间接着演，进出 `full` 时小跑）、图解区在两种版式之间的缩放、转场音效、字幕（跟着句子走，不属于转场）、`"transition": "cut"` 的硬切、锚点落在转场窗口内时元素并入进场。

### 5.4 判据

转场的任何一帧里，旧镜头的文字（标题、标签）和新镜头的文字不同时可见；两边透明度都大于 0.02 就算同时可见。
