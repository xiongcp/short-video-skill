# 安装与部署

topic-to-video 是一个 Agent skill：装进 agy、Claude Code 或 Codex 后，在对话里说一句话就能得到讲稿、分镜，以及本机渲染的解说视频。用法见 [使用指南](使用指南.md)。

## 1. 两档各需要什么

| 档位 | 产出 | 需要 |
| --- | --- | --- |
| L0 文本包 | `project.json`、`讲稿.md`、`分镜.md`、`提示词包.md` | 只要一个能用 skill 的 Agent，不需要安装任何东西 |
| L1 本地成片 | 在 L0 之外出 `out/final.mp4`、字幕、封面和 QA 报告 | Node 20 或更高（推荐 22 LTS 或更新）、FFmpeg 和 FFprobe、运行时包 `@resvg/resvg-js`、中文字体，再加一种配音来源：edge-tts、uvx（自动调用 edge-tts）或 macOS `say`，也可以用你自己的录音 |

缺 L1 的任何一项时，skill 不会自己去装，而是交付 L0，并把缺了什么、怎么装告诉你。全程不需要 API key，也不产生费用。

## 2. 安装 skill

把仓库里的 `skills/topic-to-video/` 整个目录复制到 Agent 读取 skill 的目录：

| Agent | 用户级（所有项目可用） | 项目级（只在这个仓库可用） |
| --- | --- | --- |
| Claude Code | `~/.claude/skills/` | `.claude/skills/` |
| Codex | `~/.agents/skills/`（官方文档也列出 `~/.codex/skills/`） | `.agents/skills/` |
| agy | `~/.gemini/antigravity/skills/` | `.gemini/skills/` |

macOS 和 Linux（以 Claude Code 用户级为例）：

```sh
git clone https://github.com/xiongcp/short-video-skill.git
mkdir -p ~/.claude/skills
cp -R short-video-skill/skills/topic-to-video ~/.claude/skills/
```

Windows PowerShell：

```powershell
git clone https://github.com/xiongcp/short-video-skill.git
New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item -Recurse short-video-skill\skills\topic-to-video "$HOME\.claude\skills\"
```

装到别的 Agent 时，把目标目录换成上表里对应的那一个。下文用 `<skill>` 代表装好的 `topic-to-video` 目录，例如 `~/.claude/skills/topic-to-video`。

## 3. 启用 L1 本地成片

```sh
# 运行时包（只有这一个）
npm install --prefix <skill>/scripts
```

FFmpeg（自带 FFprobe）：

| 系统 | 命令 |
| --- | --- |
| macOS | `brew install ffmpeg` |
| Ubuntu / Debian | `sudo apt-get install -y ffmpeg` |
| Windows | `winget install --id Gyan.FFmpeg` |

中文字体：macOS 和 Windows 系统自带，不用装。Linux 运行 `sudo apt-get install -y fonts-noto-cjk`。想换字体时，把环境变量 `SVS_FONT` 指向字体文件。

配音（任选一种）：

| 系统 | 命令 |
| --- | --- |
| macOS | `brew install uv`（之后自动用 `uvx --from edge-tts`），或 `pipx install edge-tts`；不装也能用系统自带的 `say` 离线配音 |
| Linux | `pipx install edge-tts`，或安装 uv |
| Windows | `winget install --id astral-sh.uv`，或 `pipx install edge-tts` |

## 4. 验证

```sh
node <skill>/scripts/doctor.mjs
```

| 字段 | 意思 |
| --- | --- |
| `l1_ready` | `true`：Node、FFmpeg/FFprobe、`@resvg/resvg-js` 和中文字体都在，可以本机出片 |
| `tts_ready` | `true`：找到了 edge-tts、uvx 或 macOS `say`，能自动配音 |
| `missing` | 缺了哪几项，例如 `["ffmpeg", "cjk-font"]` |
| `hints` | 每个缺项在你这台机器上的安装命令 |
| `recommended_voice` | 本机能用的配音设置，Agent 出片前会写进项目 |

两项都是 `true` 后，第一次试跑可以在 Agent 里说：

> 用 topic-to-video 把"为什么天空是蓝色的"做成 2 分钟的解说视频。

在 Apple M2 上，这条从确认到成片约 3 分钟，其中配音约 1 分钟，渲染约 1.5 分钟。

## 5. 团队和项目级部署

- 让整个团队共用同一个版本：把 `topic-to-video` 目录提交到项目仓库的 `.claude/skills/`（Claude Code）或 `.agents/skills/`（Codex），队友拉代码就能用。`scripts/node_modules` 不要提交，每台机器各自运行一次 `npm install --prefix`。
- 云沙箱、CI 等没有 FFmpeg 的环境：doctor 报 `l1_ready: false`，skill 自动交付 L0 文本包，不会报错中断。
- 出片的项目文件夹建在当前工作目录下，不会写进 skill 目录。

## 6. 升级与卸载

- 升级：拉取新版本，删掉旧的 `topic-to-video` 目录，再复制新目录，重新运行 `npm install --prefix <skill>/scripts`，最后跑一次 doctor。版本变化看仓库的 `CHANGELOG.md`。
- 卸载：删掉 `<skill>` 目录即可。已经做好的项目文件夹不受影响。

## 7. 联网与隐私

- edge-tts 免费，但需要联网，每句讲稿会发给微软的朗读服务。Agent 会在确认讲稿时提醒你。
- 不想联网时，可以用 macOS `say` 离线配音，或者把自己的录音放进项目（见使用指南"试听和换配音"）。
- 除配音外，渲染、QA 都在本机完成；不上传资料，也不需要任何 API key。

## 8. 常见安装问题

| 现象 | 原因与处理 |
| --- | --- |
| `l1_ready: false`，`missing` 里有 `node>=20` | Node 太旧，安装 22 LTS 或更新版本 |
| `missing` 里有 `ffmpeg` 或 `ffprobe` | 按第 3 节安装 FFmpeg；装完重开终端，确保 `ffmpeg -version` 能运行 |
| `missing` 里有 `@resvg/resvg-js` | 没运行或装错了位置，运行 `npm install --prefix <skill>/scripts` |
| `missing` 里有 `cjk-font` | Linux 没有中文字体，安装 `fonts-noto-cjk`，或用 `SVS_FONT` 指定字体文件 |
| 成片里中文变成方块 | 同上，是字体问题；装好后重新出片 |
| 出片时报 `TTS_FAILED` | 多半是 edge-tts 连不上微软的服务：检查网络或代理，或者改用 macOS `say`、自己的录音。已合成的句子会保留，下次不重配 |
| `tts_ready: false` | 没有任何配音工具，按第 3 节装一个；有自己的录音也可以直接出片 |
| Windows | 安装步骤已写好，但还没有在 Windows 上完整实测；遇到问题请提 issue |
