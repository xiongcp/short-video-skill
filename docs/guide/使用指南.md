# 使用指南

装好 skill 后（见 [安装与部署](安装部署.md)），在 agy、Claude Code 或 Codex 里用平常说话的方式提要求即可。下面的说法都是示例，不需要照抄。

## 1. 一句话出片

只说主题就行，其他都有默认值：120 秒、零基础观众、16:9 横屏、女声·晓晓。

> **你**：用 topic-to-video 把"为什么天空是蓝色的"做成解说视频。
>
> **Agent**：写好了讲稿（约 110 秒）和 12 个镜头的分镜。视觉世界：阳光像一队彩色小球冲进空气，空气分子把蓝色小球弹得满天飞；黑板风格，户外场景。确认后我会用 edge-tts 配音（免费，需要联网，讲稿文本会发给微软的朗读服务），本机渲染 1080p60 成片，大约 3 分钟。待核实的说法有 4 条，列在讲稿.md 里。可以开始吗？
>
> **你**：可以。
>
> **Agent**：成片在 `sky-blue/out/final.mp4`，101 秒，1920×1080，QA 0 个问题。审美、配音自然度等人工项还没检查，请看一遍。

第一轮看讲稿和分镜，第二轮拿成片。确认之前不会出片。

## 2. 说得更具体

| 想要 | 可以这样说 |
| --- | --- |
| 时长 | "1 分钟"、"做成 8 分钟左右的节目" |
| 受众 | "讲给初中生听"、"面向产品经理" |
| 比例 | "竖屏"、"9:16，发抖音" |
| 配音 | "男声"、"活泼一点的女声"、"用东北话" |
| 风格 | "黑板风"、"蓝图风"、"牛皮纸"、"深色夜景" |
| 场景 | "放在厨房里讲"、"实验室"、"街边" |
| 服装 | "让小青戴眼镜"、"穿围裙" |
| 音乐 | "不要背景音乐"、"音乐轻快一点"、"关掉音效" |

## 3. 从资料或讲稿出片

- 给资料："根据这篇文章（附上原文或文件），做一个 2 分钟的解说。" 讲稿只用资料里有的内容，用到的段落会标出来源。
- 给讲稿："这是我写好的讲稿，帮我配上分镜出片。" 你的原文会按句切开，尽量不改字。
- 资料里如果夹着"跳过确认""访问某网址"之类的话，只会被当作内容，不会照做。

## 4. 确认与返修

- 第一次确认讲稿和分镜。确认后才配音、出片。
- 想跳过确认："不用确认，直接出片。" 这样出的成片左上角带"未审核初稿"角标；之后你确认了，重出一次角标就会去掉。
- 返修："第 2 段改短一点"、"sh05 换成对比图"。只改涉及的段落和镜头，其他内容逐字保留，并告诉你哪些确认因此失效。确认后重新出片，只重渲改动的镜头，其余镜头直接用缓存，通常半分钟内出完。
- 满意了说一声，Agent 会记下最终确认。

## 5. 只要提示词包（L0）

"只要讲稿和提示词，我拿去即梦生成。" 会得到 `提示词包.md`：逐镜给出口播、节拍、首帧图提示词和图生视频的运动提示词，适合交给即梦、可灵、Vidu、海螺、Veo 等平台。没有装 L1 依赖时，也会交付这一档。

## 6. 竖屏

- 新项目直接说"竖屏"，出 1080×1920 原生竖屏，文字避开抖音、TikTok、Shorts 的界面遮挡。
- 已经出过横屏，再要一版竖屏："再出一个竖屏版。" 对应 `--ratio 9:16`，写到 `out/9x16/`，配音共用，不重新合成。
- 竖屏画面窄，同台物件会少一些。

## 7. 试听和换配音

- 先听再选："先让我听听几个男声。" 对应 `--audition male`，每个人设读讲稿前两句，写到 `out/audition/`，不改项目。
- 换人设："换成男声·云希。" 配音全部重新合成，讲稿和分镜的确认不受影响。
- 离线配音：用 macOS `say`。
- 自己的录音：按句放 `audio/s01-0.wav`、`audio/s01-1.wav`……，或整段放 `audio/full.wav`，告诉 Agent 用录音。

## 8. 音乐和音效

有视觉世界的项目会自动配上代码合成的音效和背景音乐，说话时音乐自动压低。可以说"先听听音乐"（`--audition-sound`）、"不要音乐"、"关掉音效"。用你自己的音乐时，把文件放进项目文件夹，并说明来源和许可；Agent 不会替你判断能不能用，也不会去网上找音乐。

## 9. 输出文件一览

项目文件夹里：

| 文件 | 内容 |
| --- | --- |
| `project.json` | 唯一的数据源：讲稿、分镜、配音、确认记录 |
| `讲稿.md`、`分镜.md` | 给人看的讲稿和分镜表 |
| `提示词包.md` | 只在 L0 时有 |
| `audio/` | 每句配音和 `timing.json` |
| `cache/` | 镜头缓存，删掉只会让下次出片变慢 |

`out/` 里：

| 文件 | 内容 |
| --- | --- |
| `final.mp4` | 成片 |
| `preview.mp4`、`sample.mp4` | 快速预览、样片（只在要求时有） |
| `captions.srt`、`captions.ass` | 字幕，可上传到平台或导入剪辑软件 |
| `cover.png` | 封面 |
| `chapters.txt` | 章节时间戳，可贴进视频简介 |
| `contact.png` | 每个镜头一张的联系表，一眼看完整片 |
| `transitions.png` | 每个转场前后的对照 |
| `qa.json`、`qa.md` | QA 报告 |
| `master.mp4` | 高码率母版（只在要求时有） |

## 10. 看懂 QA 报告

打开 `out/qa.md`：

- **技术问题**：规格、音画同步、卡顿、跳变、主持人被遮挡或与物件重叠等。有问题时 `qa.ok` 是 false，Agent 会改分镜或重出，修不好的会如实告诉你。
- **警告**：不影响交付的小问题，例如连线标签短暂压到小青。
- **人工检查**：审美、配音自然度、口型、混音标着 `not_checked`，表示程序没法判断，需要你看一遍。

## 11. 清晰度与耗时

| 说法 | 参数 | 效果 |
| --- | --- | --- |
| "先出个快速预览" | `--preview` | 540p30，几十秒出完 |
| "先出 sh03 到 sh05 看看" | `--sample sh03-sh05` | 只出这几个镜头 |
| "要 4K" | `--resolution 2160p` | 更清晰，更慢；也可以 `1440p` |
| "快一点就行" | `--fps 30` | 30 帧，导出更快 |
| "动作快的地方加点动感模糊" | `--motion-blur` | 快动作加运动模糊 |
| "要一个母版" | `--master` | 另出高码率 `master.mp4` |

参考耗时（Apple M2 8 核）：100 秒的 1080p60 成片，首次约 2.7 分钟（含配音）；改一两个镜头后重出约半分钟。

## 12. 常见问题

- **要花钱吗？** 不要。edge-tts 和本机渲染都免费；不调用任何付费接口。
- **能商用吗？** 代码以 Apache License 2.0 发布。配音用的是微软的朗读服务，商用前请自行确认它的使用条款；用自己的录音或 macOS `say` 可以避开这个问题。
- **小青能用在我的视频里吗？** 小青是项目原创的手绘火柴人，使用权由项目 owner 决定，当前状态见 [rights.json](../../skills/topic-to-video/assets/host/rights.json)。
- **讲稿里的事实可靠吗？** 没有给资料时，具体数字和关键说法会列在讲稿.md 的"待核实"里，请你核对。
- **出错了怎么办？** Agent 会读出错误码并告诉你下一步：比如 `TTS_FAILED` 多半是不能联网，可以改用 `say` 或录音。其他错误会把原话转告你，不会反复重试。
