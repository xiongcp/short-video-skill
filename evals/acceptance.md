# 验收矩阵

简体中文 · [English](acceptance.en.md)

`check_design.py` 校验架构包和纸面分镜，也可通过 `--media` 逐帧校验本地 MP4。`test_design.py` 使用改坏的规划副本，`test_media_acceptance.py` 使用实际编码的校准片。下表保留原稿需求映射。正式制作的故障注入、验收条件与放行责任见[升级验收计划](../docs/upgrade/验收计划.md)，当前结果见[交接状态与证据](../docs/upgrade/交接状态与证据.md)。

| 原稿用例 / 范围 | 测试动作 | 本包可查 | 生产验收应留存 |
| --- | --- | --- | --- |
| E2E-01 · 主题、已有稿件 | 用默认值启动一个主题，输入现成讲稿时保留原段落 | 入口、合同及两组完整规划文件 | 生成记录、段落映射、G1/G2 决定及可播放初稿 |
| E2E-02 · 质量优先 | 尝试跨过 G2 配音、跨过 G3 正式渲染或跨过 G5 打包 | 正向状态图含 G1–G5，增添 G5 旁路的回归应失败 | 宿主拒绝事件、工具调用数、旧审批哈希失效 |
| E2E-03 · 快速初稿 | 在已授权预算内生成待审核版本，再提出正式导出 | 草稿路径以 DRAFT_READY 终止，添加直通交付边会被拒 | 预览水印、问题清单、升级后的有效批准 |
| DUR-01 · 短片 | 分别输入 59、60、120、180、181 秒 | short 边界与 2 分钟 14 镜规划 | 60/120/180 秒媒体探针、旁白与字幕端点 |
| DUR-02 · 长片 | 输入 449、450、480、510、511 秒，破坏第 5 章起点 | standard8 边界、7 章 34 镜、跨章缺口的负例 | 约 8 分钟真实节目、章口联系表、连续试听 |
| RES-01 · 研究 | 删除 supported 的支持链接，准备冲突、过期资料 | 悬空/无支持关联被拒，可表达冲突与限定 | 原文定位、内容编辑决定和复核时间 |
| SCR-01 · 讲稿 | 修改含限定词的原稿、指定严格片长 | 段落 ID、论点关联、章节估时、cue 可回到原句 | 差异稿、试读记录、修改后的 G2 |
| SB/CHR-01 · 分镜、角色 | 错引 cue、调用未登记手势、把高亮放到镜头末帧之外 | 三类负例均会失败 | 编译拒绝证据、极值姿态图、角色盲评 |
| AUD-01 · 声音 | 中英混读、数字、停顿、纠正术语读音 | 词锚、采样、音轨、字幕与词典合同 | 对齐误差分布、试听、人声与背景声分轨 |
| EDIT-01 · 字幕样式 | 只改字幕颜色 | 返修依赖规则、ChangePlan 合同 | 调用日志中 TTS/图像/视频生成、角色烘焙均为零 |
| EDIT-02 · 单镜表情 | 只改 shot_001 的表情 | 角色表演与图层的版本边界 | 受影响镜头集合、命中哈希、局部预览 |
| EDIT-03 · 改写旁白 | 第 4 章减 10 秒 | 设计中给出 8,100 → 7,800 帧和远端复用规则 | 重配段落、新 SRT、总时长与更新清单 |
| FAIL-01 · 付费回执未知 | 已提交后模拟丢回执 | ToolResult 拒绝 unknown 配合自动重试 | 预留记录、查询结果、实付账单无重复 |
| FAIL-02 · 中断恢复 | 第 4 章中途终止 worker 再恢复 | 作业与 ChapterCheckpoint 合同 | 已完成镜头无重复执行，损坏缓存重建，章尾帧一致 |
| QA-01 · 缺失媒体 | 删除一条资产引用，再模拟字体缺失或损坏音轨 | 悬空图层引用负例 | 自动 QA 阻断报告、帧号、媒体探针和修复结果 |
| SEC-01 · 工具与预算 | 输入材料夹带工具指令、未授权调用或预算超额 | 权限表与默认关闭的视频策略，候选数负例 | 宿主拒绝、账本不变、审计记录 |
| EXP-01 · 可编辑交付 | 改动 G5 清单中的一项，再尝试打包 | 清单、目标哈希及收据合同 | 拒绝旧签名，正式归档解包逐项验哈希、重开项目 |

每次样片记录角色、Rig、音色、字体、模型和渲染器版本。按照同一快照重复抽取固定帧，比较像素和音频采样。连续生产验收按单片报告成功率、缓存命中、人工返修时长、实支与每分钟成本，样本量和统计口径随报告保留。
